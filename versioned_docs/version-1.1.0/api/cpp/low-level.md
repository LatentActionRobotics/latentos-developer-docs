# Low Level API

:::tip
**SDK 1.1.0 不提供 `low_level` 模块。**

:::

本版本安装包中不包含关节状态订阅与直接关节命令相关的头文件、CMake package（`latentos_sdk_low_level` / `latentos::sdk_low_level`）及示例。若业务需要关节读写能力，请使用已包含该模块的后续 SDK 版本，并参阅对应版本的 API 文档。
