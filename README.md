公司简介：[https://latent-action.com](https://latent-action.com/about.html)

## 本地开发

需要 Node.js ≥ 20。

```bash
npm install
npm start
```

构建静态站点：

```bash
npm run build
npm run serve   # 可选，预览 build/
```
