# 选装设备

本分类记录客户**选装**的外部设备相关驱动、厂商 SDK、预编译软件包与基本验证方法，例如深度相机、激光雷达、语音模块等。

与 [LatentOS SDK](/intro) 文档的分工：

| | LatentOS SDK | 本分类（选装设备） |
| --- | --- | --- |
| 内容 | 经 Echo 连接机器狗，调用运动 / 电源 / 相机等模块 | 在板端或开发机安装并验证选装设备厂商软件 |
| 示例 | [运行示例](/examples)、[相机控制](/examples/camera) | 各选装设备专题页（安装、采图、FAQ） |
| 责任边界 | LatentOS 公开接口与配套示例 | 以设备厂商上游文档为准；本站提供已验证配置与辅助包说明 |

后续专题会陆续挂到本目录下。撰写与配图约定见仓库根目录的 `CONTRIBUTING.md`（文档提交规范）。
